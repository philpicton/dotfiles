## Development Guidelines

Load these with the Read tool on a need-to-know basis, only when relevant to the task at hand. Once loaded, treat their content as mandatory instructions that override defaults.

- TypeScript, Nuxt, Vue code style and best practices: `~/.claude/docs/typescript_nuxt_vue.md`
- Nuxt, TypeScript unit testing guidelines: `~/.claude/docs/ts_unit_testing.md`

## Project Instructions

If a project has an `AGENTS.md` (and no `CLAUDE.md` that covers it), read it at the start of work in that project; it may overrule these rules as described in the general guidelines.
